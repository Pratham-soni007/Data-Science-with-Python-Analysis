# Data-Science-with-Python-Analysis
Developed a Python-based beauty product analytics project using Pandas, NumPy, Matplotlib, and Seaborn to analyze product ratings, pricing, brands, and categories. Performed data cleaning, exploratory data analysis, correlation analysis, and visualization to identify patterns and support data-driven insights.

# Project Overview
This project focuses on analyzing beauty and cosmetics product data using Python to uncover patterns in product ratings, pricing, brands, and categories. It uses exploratory data analysis (EDA), statistical summaries, correlation analysis, and data visualization to understand relationships between product characteristics and customer ratings.

# Objectives
Analyze product ratings across different brands and categories.
Explore the relationship between product prices and ratings.
Investigate the association between review counts and ratings.
Compare ratings across skin types and main ingredients.
Examine price and rating differences between cruelty-free and non-cruelty-free products.

# Technologies Used
Python
Pandas and NumPy
Matplotlib and Seaborn
Jupyter Notebook in VS Code

# Key Activities
Data inspection and cleaning
Exploratory Data Analysis (EDA)
Correlation analysis
Data visualization using charts and plots
Interpretation of patterns and analytical findings


# Objective
To apply practical data analysis techniques to beauty product data and generate insights that can support better understanding of product ratings and pricing patterns.
